Pronto para Produção

Guia Passo a Passo: AI Studio → GitHub → Hostinger

1. Ficheiro Único Pronto (`index.html`) Este código já inclui HTML5, estilização Tailwind CSS, ícones Lucide e o motor 3D Canvas/Parallax num único ficheiro `index.html`. Não requer compilação complexa para funcionar na Hostinger.
2. Subir para o Repositório GitHub
  1. Crie um repositório no GitHub (ex.: acas-website).
  2. Guarde este código com o nome exato index.html na raiz do repositório.
  3. Faça Commit e Push para a branch main.
3. Conectar o GitHub à Hostinger (hPanel)
  1. No painel da Hostinger (hPanel), aceda a Sites → Gerenciar → Git (em Avançado).
  2. Cole o endereço do seu repositório: https://github.com/SEU-USUARIO/acas-website.git e a branch main.
  3. Deixe o diretório de instalação em branco (vai direto para public_html) e clique em Implantar (Deploy).
  4. Ative o botão Implantação Contínua (Webhook) para que qualquer alteração no GitHub atualize o site acasconsultmz.com automaticamente!
